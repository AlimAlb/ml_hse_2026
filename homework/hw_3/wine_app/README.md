# Подборка вин

[Открыть приложение](https://wineapp-eq4vkjfwupybqkyzhyred8.streamlit.app/)

Приложение оценивает вероятность того, что эксперты поставят вину 7 баллов или выше. Порог из боковой панели применяется к одному вину, тестовой выборке и загруженному CSV.

## Локальный запуск

Нужен **Python 3.12**. Из папки `wine_app` запустите следующие команды.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для Windows используйте `py -3.12 -m venv .venv` и `.venv\Scripts\Activate.ps1` в PowerShell. 

В папке уже есть обученный пайплайн, порог и тестовая выборка. Для повторного экспорта запустите `HW3_MMDA.ipynb` из папки `homework/hw_3` до ячейки сохранения модели. Используйте ту же версию scikit-learn, что указана в зависимостях приложения.

## Пакетный прогноз

В CSV нужны 12 столбцов признаков из `test.csv`, без `target`. Для `is_red` передавайте 0 для белого вина и 1 для красного. В скачиваемом файле `probability` содержит вероятность хорошей оценки, а `recommend` содержит решение (1 означает «добавить в подборку»).

## Кэширование

`st.cache_resource` хранит один объект модели на сервере. Приложение использует его для предсказаний во всех сессиях. Без декоратора `joblib.load` снова читает файл и восстанавливает модель после каждого действия пользователя.

`st.cache_data` хранит сериализованные таблицы и массивы и возвращает копии. Так приложение читает тестовую выборку и считает её вероятности один раз. При изменении порога эти вероятности используются повторно для расчёта метрик.
